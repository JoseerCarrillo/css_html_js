DIRECTORIO WEB
Miniaplicación desarrollada para la guía práctica de Programación Web (HTML, CSS, JavaScript, Fetch API y diseño responsive). Consume la API pública https://jsonplaceholder.typicode.com/users y representa cada usuario como una tarjeta en el DOM.
Estructura del proyecto
guia-fetch/
├── index.html
├── css/
│   └── style.css
└── js/
    └── app.js

Nota: verifica que el nombre de tu archivo CSS coincida exactamente con el href de index.html (css/style.css). Si tu archivo se llama distinto, el navegador no cargará los estilos.
Cómo ejecutarlo
Descarga o clona la carpeta del proyecto.
Abre index.html en el navegador (o sírvelo con una extensión tipo "Live Server").
Abre las DevTools (Network y Console) para observar la solicitud a la API.
